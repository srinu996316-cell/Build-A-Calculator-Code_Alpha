# 🧮 Calculator Pro

A modern, responsive calculator built with **HTML, CSS, and JavaScript**, featuring a clean glassmorphism interface, calculation history, keyboard support, and light/dark themes.

## ✨ Features

* ➕ Basic arithmetic operations
* 🧮 Real-time calculation
* 🕘 Calculation history
* ⌨️ Keyboard support
* 🌙 Dark and ☀️ Light theme
* 📱 Responsive design
* 🎨 Modern glassmorphism UI
* ⚡ Fast and lightweight
* ♿ Accessible interface with ARIA support

## 🛠️ Technologies Used

* **HTML5** — Application structure
* **CSS3** — Styling, responsive design, and glassmorphism effects
* **JavaScript** — Calculator logic, history, keyboard controls, and theme switching
